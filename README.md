# cpp-leetcode

My C++ solutions to LeetCode problems. A growing collection focused on writing clean, modern C++ and choosing the right data structure for each problem.

## Goals

- Prioritize optimal time and space complexity
- Pick the best data structure for the job (no brute force where a hash map or set will do)
- Write clean, idiomatic modern C++ with strong use of the STL
- Build fluency for coding interviews and algorithmic problem-solving

## Structure

Solutions are organized by problem. Each file is named for its LeetCode problem number and title.

```
cpp-leetcode/
├── 0001-two-sum.cpp
├── 0217-contains-duplicate.cpp
├── 0242-valid-anagram.cpp
└── ...
```

## Topics Covered

- Arrays & Hashing
- Two Pointers
- Sliding Window
- Stacks
- Strings
- ...and more as the collection grows
